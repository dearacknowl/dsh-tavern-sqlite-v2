- **前台队列源切点**：回退清理的队列切分按**真实前台来源**判定（`foregroundExact`），并透传到 `cleanupAfterRollbackAtSeq`；首轮目标 prepend 到更早的独立队列时，**独立队列保留**，只清目标前缀，不套用后台首队兼容口径。

- **适配与边界**：沿用 0.4.11 的适配基线，**未新增上游兼容声称**；跨库**不声称原子**；"所有生产者无条件保证"**未达**，缺前像**不猜**、响亮拒绝。

## 更新内容

### 最新一次发送的统一撤销

- **不看终态、不看产物**：最新一次发送无论是正常成功、报错、未知终态、被中断，还是只留下用户输入、部分输出、已有正文或变量，都提供同一个"回退到这次发送之前"的入口。**是否回退/清理由你自己决定**；不强制先清理错误轮，不自动墓碑清除失败输入，停止后可以直接继续普通发送。文档与测试里的场景只是样例，不是资格名单。
- **发轮前基准**：复用作者原生锚点（`nativeAnchor`）与原始输入事件坐标；只有 `turn/start`、玩家输入尚未到达时**不猜**输入序号。发轮前业务前像写入既有正文操作的 `businessBefore`，不新增基准表、第二身份或第二存储。
- **任何停止时机都能回退**：为保证"发出去就停了"也能回到发送前，基准在原生轮开始**之前**同步落库；后续准备阶段复用同一操作占位、**不覆盖**已存前像，玩家输入到达后再补锚点。
- **并发与迟到写**：旧的异步写入在提交前核对实际数据库 revision，早期捕获推进过即拒绝覆盖，不会把新基准冲掉；撤销执行端先校验目标身份与锚点原始事件归属，再取消在途前台、静止写入、重读核对同一轮，最后走既有的物理纯尾（SQL 事务删尾、前像恢复、派生清理、同连接同步）。
- **停止/取消不算资格问题**：取消自身产生的合法终态写入允许推进 revision，不会因此拒绝你的撤销请求。
- **目标选择**：视图签发统一的 `kind:rollback` 目标（存档/会话/分支/revision/轮号，可带操作身份与锚点）；数字旧入口同样选择**最新**发送，不因历史失败改选更早轮；最新原生轮缺基准时**拒绝签发**并说明原因，绝不回落到更早轮。
- **窄窗口**：只读窗口下，已完成的正文操作、同轮检查点、以及仅检查点留有基准的情形都能正常签发撤销目标。
- **重新生成**：重新生成开启的临时原生轮，其早期正文占位在物理采用时**删除**，不会把"重新生成前的完成态"改号冒充原轮发送前基准；原轮基准保留。
- **入口**：有统一目标时，菜单不再因前台生成中、后台忙或结算中而禁用（点击后由后端先取消并收口再回退）；**重新生成与正文编辑的互斥门未改动**。
- **范围边界**：存档库与原生会话是不同数据库，不声称跨库原子；回退只恢复本档剧情/变量/进度/该轮运行数据，库卡、外部世界书、共享编辑、脚本源与用户配置保留。不会自动迁移、清理或删除既有存档。

- **安装入口单源**：包内二入口（`install.sh`、`deploy/install.sh`）与外部发行件由 `scripts/render-install-sh.mjs` 从 `deploy/install.template.sh` ＋ `deploy/bootstrap.mjs` ＋ 当前 `package.json` 版本渲染。包内保持 URL/SHA 占位（内嵌本次 tgz 摘要会自引用），外部件在摘要产出后由同一函数填一次地址与摘要；构建门禁校验版本/数值语义与内嵌体逐字节一致。

- **公开 API 兼容与退役策略**：[PUBLIC-API-COMPATIBILITY.md](<../PUBLIC-API-COMPATIBILITY.md>)——56 个导出保留（prod 44 / deploy-only 7 / test-only 1 / zero 2 / infra 2）；deprecated 只做注记；移除需大版本与外部证据；外部集成只经公开服务/命令面，不直接写库。
